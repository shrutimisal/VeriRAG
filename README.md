# VeriRAG

Citation-Aware Document Intelligence
and RAG Evaluation System.

## Overview

VeriRAG is a document-based question
answering system that uses Retrieval-
Augmented Generation (RAG).

It aims to generate answers from uploaded
documents, provide traceable citations,
and evaluate the reliability of generated
responses.

## Tech Stack

- Python
- PyMuPDF
- Sentence Transformers
- ChromaDB
- Gemini API
- RAGAS
- Streamlit
